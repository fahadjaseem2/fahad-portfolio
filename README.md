# Fahad Jaseem — DevOps Portfolio

A modern single-page portfolio for **Fahad Jaseem, DevOps Engineer**, built with plain HTML, CSS, and JavaScript.

The portfolio highlights experience and hands-on work across **AWS, Docker, Kubernetes, Terraform, Ansible, GitHub Actions, CI/CD, and DevSecOps**.

## Design

The design is inspired by a CI/CD pipeline:

- Terminal-style hero section
- Pipeline-inspired navigation
- Status indicators inspired by GitHub Actions and Kubernetes health probes
- Scroll progress indicator
- Terminal typing animation
- Reveal-on-scroll animations
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify

No framework or build system is required.
